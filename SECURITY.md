# Sicherheit

Notchwerk ist ein privates Hobbyprojekt. Wenn du eine Sicherheitslücke findest, melde sie bitte vertraulich über **Security → Report a vulnerability** hier auf GitHub (Security Advisory) statt als öffentliches Issue. Ich antworte so schnell, wie es neben Studium und Alltag geht.

Was die App tut und nicht tut, steht in der README unter „Sicherheit“ und „Was die App auf deinem Mac verändert“. Kurzfassung: nur 127.0.0.1, zufälliger Token pro Start, keine Fremdbibliotheken, keine Telemetrie, keine Netzverbindung außer der optionalen Nutzungsanzeige zu api.anthropic.com.
